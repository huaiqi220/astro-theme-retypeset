很久以前我就写过相关的文档，教怎么在 Windows 上使用 Clash，写了还总有人一直来问，因此在这里重新写一遍。

当微信联系我的时候，我会发一个网址和一个 Windows / 安卓的软件安装包。

![软件安装包](https://img.shenshijiu.com/clash/pic1.jpg)

然后安装软件，可以进入软件的主界面。安装软件的过程就不再次展示了。

首先明确一些基本概念：

Clash 只是一个转发网络数据的软件，Clash 必须搭配”订阅”才能够使用。订阅可以理解为一大堆转发网络数据的海外服务器的集合。

![订阅界面](https://img.shenshijiu.com/clash/pic2.jpg)

点击左侧”订阅”按钮，在订阅按钮的上方输入从我这获得的链接。

![输入订阅链接](https://img.shenshijiu.com/clash/pic3.jpg)

输入链接后点击导入，即可从网址上下载订阅到本地。

![导入订阅](https://img.shenshijiu.com/clash/pic4.jpg)

有时候有人会问，为什么我点了导入，还是无法导入？

需要检查当前”系统代理”功能是否关闭，必须关闭系统代理时电脑才能正确下载订阅。

否则当电脑打开了”系统代理”，但订阅已经过期，或者没有订阅的时候，电脑会无法访问任何网络。

![关闭系统代理](https://img.shenshijiu.com/clash/pic5.jpg)

在订阅导入成功以后，我们需要到”代理”界面，选择需要的代理服务器位置。根据开展的业务，比如我要访问美区服务等，就选择美国的转发服务器。

![选择代理服务器](https://img.shenshijiu.com/clash/pic6.jpg)

在选择完服务器之后，回到”首页”。首页中有”系统代理”与”虚拟网卡模式”，建议使用系统代理模式，在不需要 VPN 服务的时候，将系统代理功能关掉，按需打开。

![系统代理与虚拟网卡](https://img.shenshijiu.com/clash/pic7.jpg)

<!-- ![首页概览](https://img.shenshijiu.com/clash/pic8.jpg) -->

> **提示**：关闭电脑前记得关闭 Clash 的系统代理模式。如果没有关闭，重启电脑后可能电脑没网。这时候可以打开 Clash，关闭系统代理模式即可。

## 常见问题与提示（新手必看）

### 1. 导入订阅失败怎么办？

**现象**：输入订阅链接后点击导入，一直转圈或者提示失败。

**原因**：你的电脑之前可能连着一个已经失效的订阅，并且系统代理还开着。此时 Clash 试图通过失效的代理服务器去下载新订阅，自然连不上。

**解决**：先到"首页"把**系统代理关掉**，再回到"订阅"页面重新导入，导入成功后再重新打开系统代理。

简单记：**导入订阅前，系统代理必须是关闭状态。**

### 2. 为什么关了 Clash 电脑就上不了网？

Clash 开启系统代理时，会修改 Windows 的网络代理设置，把流量指向 Clash。如果直接关掉 Clash 而没有先关闭系统代理，Windows 的代理设置还指着 Clash，但 Clash 已经不在了，所以浏览器找不到路。

**解决**：重新打开 Clash，把系统代理关掉，再关闭 Clash。或者去 Windows 设置 → 网络和 Internet → 代理 → 关闭"使用代理服务器"。

### 3. 虚拟网卡模式（TUN）怎么用？

首页的"虚拟网卡模式"不能直接点开就用。需要先安装 TUN 模块：

1. 进入 Clash 的**设置**页面
2. 找到 **TUN 模式** 相关选项
3. 点击安装 TUN 模块 / 安装虚拟网卡驱动
4. 安装完成后，回到首页才能正常开启虚拟网卡模式

如果没装 TUN 模块就直接开，会提示失败或者没反应，这是正常的。

### 4. 开了代理但访问不了外网？

请按顺序检查：

- **订阅是否过期？** — 到"订阅"页面查看订阅信息，过期了需要重新获取链接。
- **是否选了服务器节点？** — 到"代理"页面，点击选择一个可用的节点（比如日本、美国、新加坡等）。
- **系统代理开了吗？** — 回"首页"确认系统代理是开启状态。
- **节点是否挂了？** — 换一个节点试试，有时候个别服务器会维护。

四步都检查完，基本都能解决。

### 5. 电脑突然什么网都打不开了？

别慌，大概率是 Clash 开着系统代理但订阅失效了，或者 Clash 崩溃了但代理设置没恢复。

**快速自救三步走**：

1. 打开 Clash → 关闭系统代理 → 网络恢复
2. 去"订阅"页面更新订阅（记得关系统代理再更新！）
3. 更新成功后重新打开系统代理

### 6. 订阅链接从哪里复制？

订阅链接是一串以 `http://` 或 `https://` 开头的网址。微信上发给你的链接，需要**完整复制**，不要漏掉任何字符。复制后粘贴到 Clash 订阅页面的输入框中，确保前后没有多余的空格。
